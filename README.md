# patient-management-api
Completed T-001 Patient Management API with Spring Boot, MySQL, CRUD operations, validation, DTOs, and exception handling. APIs tested successfully using Postman.

## Project
UK Healthcare Patient Management Platform

## Module
T-001 - Patient Management API

## Technology
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- REST API
- Maven
- Postman

## Features
- Create patient
- Get patient by ID
- Get all patients
- Update patient
- Delete patient
- Request validation
- Exception handling

## API Endpoints

POST   /api/patients
GET    /api/patients
GET    /api/patients/{id}
PUT    /api/patients/{id}
DELETE /api/patients/{id}
